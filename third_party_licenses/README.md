# Bundled typeface

Auratio bundles Inter 4.1 from the [official Inter release](https://github.com/rsms/inter/releases/tag/v4.1):

- `mobile/assets/fonts/InterVariable.ttf`
- `portal/src/assets/fonts/InterVariable.woff2`

Both files are distributed under the SIL Open Font License 1.1 in `Inter-4.1-OFL-1.1.txt`. They are packaged with the applications so rendering does not depend on an installed system font or runtime network access.
